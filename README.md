# Shreya Katkar - Editable Portfolio

## Files
- index.html
- style.css
- script.js

## How to run
1. Keep all 3 files in the same folder.
2. Double-click `index.html` or open it with Chrome.
3. Click **Edit Portfolio**.
4. Change your details.
5. Click **Save Changes**.

The portfolio stores edited data in your browser's `localStorage`.

## To publish online
You can upload these files to GitHub Pages, Netlify, Vercel, or another static hosting service.
